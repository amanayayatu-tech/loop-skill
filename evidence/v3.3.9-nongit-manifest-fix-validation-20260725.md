## Root cause closed

v3.3.8 required every Adaptive Worker to use Git-only
`CAPTURE_COMPLETE_DIFF`, including a `repo_mode=non_git` Worker. The candidate
now keeps the exact Git request schema for Git roots and gives non-Git routes a
first-class `CAPTURE_MANIFEST_DELTA` operation. The existing Gateway captures
the canonical allowed-scope BEFORE receipt before `PREPARE_ROUTE` returns;
the Worker can only read back that baseline and later capture AFTER. Reports
accept only runtime-reconstructed `MANIFEST_DELTA_V1` or receipt-bound
`NO_DIFF`, with Git identity fields set to `NOT_APPLICABLE`.

The scope walk is rooted with directory file descriptors, does not follow
symlinks, opens files with `O_NOFOLLOW | O_NONBLOCK`, rejects non-regular
entries before opening, excludes case-folded `.codex-loop` aliases, and
re-enumerates wildcard scopes so additions, modifications, and deletions form
one sorted LF manifest. A project directory inside a parent Git worktree is
still non-Git unless the project root itself equals Git's top level.
